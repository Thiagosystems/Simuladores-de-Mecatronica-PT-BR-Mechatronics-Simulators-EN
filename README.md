# Simuladores-de-Mecatronica-PT-BR-Mechatronics-Simulators-EN
Laboratório interativo com 3 simulações físicas no navegador: um controlador PID com sliders de Kp/Ki/Kd e gráfico de resposta em tempo real; cinemática direta de um braço robótico 2R controlado por ângulos; e uma ponte H clicável onde você liga transistores para inverter o sentido do motor ou causar curto-circuito.
